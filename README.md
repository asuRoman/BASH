Написать скрипт для CRON, который раз в час формирует отчёт


Отчёт должен содержать:

IP-адреса с наибольшим числом запросов (ip_log_asur.sh)
Запрашиваемые URL с наибольшим числом запросов (url_log_asur.sh)
Ошибки веб-сервера/приложения (error_log_asur.sh)
HTTP-коды ответов с указанием их количества (http_log_asur.sh)

Дополнения:
1. Все скрипты отрабатывают с момента последнего запуска.
2. Каждый скрипт предотвращает одновременный запуск нескольких копий до его завершения.

Для автозапуска в CRON, нам надо:
1. Открыть crontab на редкатирование: crontab -e
2. Добавить в него строку: 0 * * * * /home/asur/cron_asur.sh
